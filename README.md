## 🧠 Descripción general

Este proyecto es un **programa de gestión de países** desarrollado en Python, como parte del **Trabajo Práctico Integrador**. El objetivo es aplicar los contenidos aprendidos sobre **funciones, estructuras de control, listas, diccionarios, manejo de archivos CSV y validaciones**. El programa permite **cargar, buscar, actualizar, filtrar, ordenar y analizar información de países**, almacenada en un archivo CSV persistente.

---

## ⚙️ Funcionalidades principales

| Opción del menú | Descripción |
|------------------|-------------|
| 1️⃣ **Agregar un país** | Permite registrar un nuevo país con su población, superficie y continente. |
| 2️⃣ **Actualizar un país** | Modifica los datos de población y superficie de un país existente. |
| 3️⃣ **Buscar un país** | Busca coincidencias por nombre y muestra su información completa. |
| 4️⃣ **Filtrar países** | Filtra por continente, rango de población o rango de superficie. |
| 5️⃣ **Ordenar países** | Ordena los países por nombre, población o superficie. |
| 6️⃣ **Mostrar estadísticas** | Calcula promedios, países con mayor/menor población y cantidad por continente. |
| 7️⃣ **Salir** | Finaliza el programa guardando los cambios. |
